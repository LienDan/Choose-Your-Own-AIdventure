# Choose-Your-Own-AIdventure
An llm controlled text based adventure in terminal.

## Requirements
Python 3.10+
Ollama installed and running.
A supported Ollama model (default: qwen3.5:4b).

## Installation
- Clone the repo or install the files.
- Install Ollama (pip install ollama)
- Download an LLM model (default: qwen3.5:4b)
- Setup up configuration file

## How to run
- Start Ollama, via terminal Ollama serve or by openning app
- Optionally, set up settings.json
- Run "python llmProject.py" in terminal
